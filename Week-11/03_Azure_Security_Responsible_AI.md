# Azure Security and Responsible AI

## 1. Objective

Understand how to secure Microsoft Azure AI resources and apply Responsible AI principles.

## 2. Manage Account Keys

Azure account keys are used to authenticate applications and access supported Azure services.

Important practices:

- Locate resource access keys in the Azure Portal.
- Keep keys confidential.
- Never publish keys on GitHub.
- Regenerate keys if they are exposed.
- Use secure configuration methods for applications.

## 3. Manage Authentication

Authentication verifies the identity of a user or application accessing an Azure resource.

Common approaches include:

- Microsoft Entra ID authentication.
- Managed identities.
- Resource keys where supported.

## 4. Azure Virtual Networks

Azure Virtual Networks provide network isolation and communication between cloud resources.

Security features include:

- Network isolation.
- Private endpoints.
- Network security groups.
- Restricted network access.

## 5. Responsible AI Principles

Responsible AI helps ensure that AI systems are developed and used appropriately.

Microsoft's six Responsible AI principles:

1. **Fairness:** AI systems should treat people fairly.
2. **Reliability and Safety:** AI systems should operate reliably and safely.
3. **Privacy and Security:** Personal information and data should be protected.
4. **Inclusiveness:** AI systems should empower everyone.
5. **Transparency:** People should understand how AI systems work.
6. **Accountability:** Organizations and individuals should be responsible for AI outcomes.

## 6. Practical Exercise

**Task:** Understand and document Azure AI resource security.

Steps:

1. Open the Azure Portal.
2. Select an existing AI resource, if available.
3. Explore its authentication settings.
4. Identify available access keys.
5. Review network access configuration.
6. Explore available security settings.
7. Document how the resource can be protected.

Do not expose actual account keys, passwords or credentials in screenshots or GitHub files.

## 7. Conclusion

Azure security involves protecting resource access, managing authentication, controlling network connectivity and protecting sensitive information.

Responsible AI ensures that AI systems are developed and operated ethically.

## 8. Learning Outcome

Understand Azure resource security, account key management, authentication, virtual networks and Responsible AI principles.
