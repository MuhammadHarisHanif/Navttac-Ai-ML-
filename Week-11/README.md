# Week 11 – Microsoft Azure AI Services

This folder contains practical exercises and documentation for Week 11 of the NAVTTC Artificial Intelligence, Machine Learning and Deep Learning course.

## Topics Covered

### 1. Azure AI Service Selection
- Select appropriate services for Vision solutions.
- Select appropriate services for Language Analysis.
- Select appropriate services for Decision Support.
- Select appropriate services for Speech solutions.
- Select Applied AI services.

### 2. Security and Responsible AI
- Manage account keys.
- Manage resource authentication.
- Secure services using Azure Virtual Networks.
- Understand Responsible AI principles.

### 3. Create and Manage Azure AI Services
- Create Azure AI resources.
- Configure diagnostic logging.
- Manage service costs.
- Monitor Azure AI resources.

### 4. Deploy Azure AI Services
- Determine service endpoints.
- Create resources using Azure Portal.
- Integrate services into CI/CD pipelines.
- Plan container deployments.
- Implement prebuilt containers in connected environments.

### 5. Anomaly Detection and Content Improvement
- Anomaly Detector.
- Azure Content Moderator.
- Personalizer.
- Metrics Advisor.
- Immersive Reader.

### 6. Image and Video Processing
- Analyze images.
- Extract text from images.
- Image classification.
- Object detection using Custom Vision.
