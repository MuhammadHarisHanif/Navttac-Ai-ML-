# Practical 7: Anomaly Detection and Content Improvement

## Objective
Understand how Azure AI services can detect unusual patterns, moderate content, personalize recommendations, monitor metrics, and improve reading accessibility.

## 1. Anomaly Detection

Anomaly detection identifies unusual patterns or values that differ from normal behavior.

**Example:** An online store normally receives 100 orders per day. If orders suddenly drop to 10, an anomaly detection system can flag the unusual change.

**Practical workflow:**
1. Collect historical data.
2. Select the relevant time-series data.
3. Configure an anomaly detection solution.
4. Analyze the results.
5. Identify unusual values and investigate their causes.

## 2. Azure Content Moderator

Content moderation helps identify potentially inappropriate content, such as unsafe text or images.

**Example:** A social media platform can review user-uploaded content before displaying it.

**Practical workflow:**
1. Prepare sample text or images.
2. Submit the content to a moderation service.
3. Review the moderation results.
4. Identify content that requires further review.
5. Apply suitable moderation rules.

## 3. Azure Personalizer

Personalizer helps select relevant content or recommendations for users based on their context and interactions.

**Example:** An online shopping website can recommend products based on a customer's interests.

**Practical workflow:**
1. Define available choices or actions.
2. Identify useful user context.
3. Configure a recommendation scenario.
4. Review the recommended action.
5. Use feedback to improve future recommendations.

## 4. Azure Metrics Advisor

Metrics Advisor is designed to monitor time-series metrics and identify unusual changes.

**Example:** A business can monitor daily website traffic and detect unexpected increases or decreases.

**Practical workflow:**
1. Prepare time-series metric data.
2. Connect the data source.
3. Configure monitoring.
4. Review detected anomalies.
5. Investigate unusual metric changes.

## 5. Azure Immersive Reader

Immersive Reader helps improve reading accessibility and comprehension.

**Features include:**
- Reading text aloud.
- Adjusting text appearance.
- Supporting reading comprehension.
- Helping users focus on individual lines or sections.

**Example:** An educational application can provide a reading experience that helps students understand learning material.

**Practical workflow:**
1. Prepare a sample text.
2. Integrate an Immersive Reader experience.
3. Test reading and display features.
4. Review accessibility improvements.

## Learning Outcome

After completing this practical, I understand the purpose and possible applications of anomaly detection, content moderation, personalization, metrics monitoring, and reading accessibility services.
