# Azure Resource Management

## 1. Objective

Understand how to create, configure, manage and monitor Microsoft Azure AI resources.

## 2. Azure Resource Creation

General steps:

1. Sign in to the Microsoft Azure Portal.
2. Open the Azure Portal dashboard.
3. Search for the required Azure AI service.
4. Select the appropriate resource.
5. Select Create.
6. Choose the subscription and resource group.
7. Select the required region.
8. Configure the resource name and pricing tier.
9. Review the configuration.
10. Create the resource.

## 3. Resource Configuration

Important resource settings include:

- Resource name
- Subscription
- Resource group
- Region
- Pricing tier
- Authentication settings
- Network configuration

## 4. Diagnostic Logging

Diagnostic logging helps administrators monitor resource activity and identify problems.

Common activities include:

- Enabling diagnostic settings.
- Selecting available log categories.
- Configuring a destination for logs.
- Reviewing resource activity.

## 5. Cost Management

Azure cost management helps monitor and control cloud expenses.

Important practices:

- Review resource pricing before deployment.
- Monitor resource usage.
- Configure budgets and alerts.
- Delete unused resources.
- Stop services when they are not required, where supported.

## 6. Resource Monitoring

Monitoring helps track the performance and health of Azure resources.

Examples:

- Monitor resource availability.
- Review usage metrics.
- Check diagnostic logs.
- Identify errors and performance issues.

## 7. Practical Exercise

**Task:** Create and manage an Azure AI resource.

Expected steps:

1. Open Azure Portal.
2. Select an appropriate AI service.
3. Configure resource settings.
4. Review security and pricing.
5. Create the resource if an appropriate subscription is available.
6. Explore monitoring and diagnostic options.
7. Document the configuration.

## 8. Conclusion

Azure resource management involves creating, configuring, monitoring and controlling the cost of cloud AI resources.

## 9. Learning Outcome

Understand the basic lifecycle of an Azure AI resource, from creation to monitoring and cost management.
