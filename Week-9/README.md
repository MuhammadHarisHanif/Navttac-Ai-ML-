# Week 9 – Deep Learning II

This folder contains practical exercises for Week 9 of the NAVTTC Artificial Intelligence, Machine Learning and Deep Learning course.

## Topics Covered

- Word Embeddings
- Word2Vec
- Continuous Bag of Words (CBOW)
- Continuous Skip-Gram
- Gensim and Custom Embedding Training
- Sequence Models
- One-to-One
- One-to-Many
- Many-to-One
- Many-to-Many

## Practical Exercises

| No. | Exercise |
|---|---|
| 1 | Word2Vec Demonstration |
| 2 | CBOW and Skip-Gram |
| 3 | Custom Word Embeddings using Gensim |
| 4 | Sequence Model Architectures |

## Technologies & Libraries

- Python
- NumPy
- Gensim
- TensorFlow / Keras
- Matplotlib

## Learning Objectives

- Understand word embeddings and their importance in NLP.
- Learn Word2Vec architecture.
- Understand CBOW and Skip-Gram models.
- Train custom word embeddings using Gensim.
- Understand different sequence-model architectures.
- Demonstrate sequence processing using neural networks.
