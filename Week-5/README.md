
# Week 5 — Machine Learning I

## Overview
This week focuses on the basic implementation of Machine Learning models using Python and Scikit-learn.

## Tasks Covered

### Task 51: Linear Regression
- Create a sample dataset.
- Split data into training and testing sets.
- Train a Linear Regression model.
- Predict numerical values.
- Evaluate the model using MAE, MSE, and R² score.

### Task 52: Logistic Regression
- Create a binary classification dataset.
- Split data into training and testing sets.
- Train a Logistic Regression model.
- Predict class labels.
- Evaluate accuracy and the confusion matrix.

## Files

| File | Description |
|---|---|
| `01_Linear_Regression.py` | Implements and evaluates a Linear Regression model |
| `02_Logistic_Regression.py` | Implements and evaluates a Logistic Regression model |

## Libraries Used
- NumPy
- Scikit-learn

```bash
python 01_Linear_Regression.py
```

```bash

```
