# Employable Project – Project Proposal

## 1. Introduction

The employable project is part of the NAVTTC Artificial Intelligence, Machine Learning and Deep Learning course.

The purpose is to apply the knowledge and practical skills gained during training to develop an independent project.

## 2. Project Objectives

- Apply Artificial Intelligence and Machine Learning concepts.
- Identify a real-world problem.
- Design an appropriate project architecture.
- Implement a practical AI-based solution.
- Develop problem-solving and technical skills.
- Prepare the project for final presentation and assessment.

## 3. Project Selection

The project should be selected according to:

- Trainee's skills and interests.
- Practical industry requirements.
- Emerging market trends.
- Business and entrepreneurship opportunities.
- Available resources and project duration.

## 4. Project Development Activities

1. Identify a problem.
2. Select a suitable project idea.
3. Define project objectives and scope.
4. Research relevant technologies.
5. Design project architecture.
6. Prepare the development plan.
7. Implement and test the solution.
8. Prepare project documentation.
9. Present the completed project.

## 5. Expected Deliverables

- Project proposal.
- Problem statement.
- Project objectives.
- System architecture.
- Technology stack.
- Implementation.
- Testing and evaluation.
- Final project presentation.

## 6. Assessment

The NAVTTC syllabus mentions a final viva/assessment of the project assignment. Projects may also be presented in skills competitions at zonal, regional and national levels.

## 7. Project Duration

The syllabus allocates two weeks for the employable project or, alternatively, two weeks of on-job industrial training.
