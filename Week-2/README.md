
# Week 2 — Functions and Exception Handling

## Overview
This week focuses on user-defined functions and exception handling in Python.

## Tasks Covered

### Task 20: User-Defined Functions
- Create and call user-defined functions.
- Pass arguments to functions.
- Return values from functions.

### Task 26: Exception Handling
- Handle runtime errors using `try` and `except`.
- Use `else` and `finally` blocks.
- Prevent programs from stopping unexpectedly due to common errors.

### Task 27: User-Defined Exceptions
- Create custom exception classes.
- Raise exceptions using the `raise` keyword.
- Handle custom exceptions using `try` and `except`.

## Files

| File | Description |
|---|---|
| `01_User_Defined_Functions.py` | Demonstrates functions, arguments, and return values |
| `02_Exception_Handling.py` | Demonstrates exception handling in Python |
| `03_User_Defined_Exceptions.py` | Demonstrates custom exception classes |

## How to Run

Run these commands in the terminal:

```bash
python 01_User_Defined_Functions.py
python 02_Exception_Handling.py
python 03_User_Defined_Exceptions.py
```

## Learning Outcome
I practiced creating reusable functions, handling runtime errors, and defining custom exceptions in Python.
