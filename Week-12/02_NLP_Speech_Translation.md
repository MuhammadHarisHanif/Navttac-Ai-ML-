# Practical 2: NLP, Speech and Language Translation

## Objective
Understand how Microsoft Azure AI solutions can analyze text, process speech, and translate languages.

## 1. Natural Language Processing (NLP)

NLP enables computers to understand, analyze, and process human language.

**Common applications:**
- Sentiment analysis.
- Text classification.
- Key phrase extraction.
- Entity recognition.
- Text analysis.

**Example:** An online business analyzes customer reviews to identify positive and negative feedback.

## 2. Analyze Text

Text analysis extracts useful information from written content.

**Practical workflow:**
1. Prepare sample text.
2. Submit the text to a suitable language analysis service.
3. Select the required analysis operation.
4. Review the output.
5. Identify useful information from the results.

## 3. Speech Processing

Speech processing enables AI systems to work with spoken language.

**Common applications:**
- Speech-to-text: converts spoken words into written text.
- Text-to-speech: converts written text into spoken audio.
- Speech recognition: identifies spoken words.
- Speech analysis: processes audio information.

**Example:** A voice assistant converts a user's spoken question into text before processing it.

## 4. Language Translation

Language translation converts text or speech from one language into another.

**Example:** Translating an English sentence into Urdu.

**Practical workflow:**
1. Prepare text in the source language.
2. Select the target language.
3. Submit the text to a translation service.
4. Review the translated output.
5. Check whether the meaning is preserved.

## 5. Applications

- Customer support systems.
- Voice assistants.
- Multilingual websites.
- Document analysis.
- Automatic transcription.
- Language learning applications.

## Learning Outcome

After completing this practical, I understand the basic concepts of NLP, text analysis, speech processing, and language translation using AI services.

## Conclusion

Azure AI language and speech solutions can help applications understand text, process spoken language, and communicate across different languages.
