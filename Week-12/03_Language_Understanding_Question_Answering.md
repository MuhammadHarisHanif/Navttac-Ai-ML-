# Practical 3: Language Understanding and Question Answering

## Objective
Understand how to build and manage a language understanding model and create a question-answering solution using Microsoft Azure AI.

## 1. Language Understanding

Language understanding enables an AI system to identify the meaning and intention behind human language.

**Example:** A user writes, "I want to book a ticket."

An AI system can identify:
- Intent: Book a ticket.
- Entity: Destination, date, or ticket type (if provided).

## 2. Important Concepts

### Intent
An intent represents what a user wants to accomplish.

Examples:
- Book a ticket.
- Check order status.
- Cancel an appointment.

### Entity
An entity represents important information extracted from a user's message.

Examples:
- City name.
- Date.
- Product name.
- Order number.

### Utterance
An utterance is a sentence or phrase provided by the user.

Example: "I want to check my order."

## 3. Build and Manage a Language Understanding Model

**General workflow:**

1. Create a language understanding project.
2. Define user intents.
3. Add example utterances.
4. Identify and label relevant entities.
5. Train the model.
6. Test the model with new sentences.
7. Evaluate the predictions.
8. Update and improve the model.

## 4. Question Answering Solution

A question-answering system provides answers to user questions using a knowledge source.

**Example:**

Question: "What are your business hours?"

Answer: "Our business hours are 9 AM to 5 PM."

### General workflow

1. Prepare a knowledge source containing relevant information.
2. Create a question-answering project.
3. Add the knowledge source.
4. Configure questions and answers.
5. Test the system with different questions.
6. Review and improve the answers.

## 5. Applications

- Customer support.
- Booking systems.
- FAQ assistants.
- Banking support.
- Educational assistants.
- E-commerce helpdesks.

## Learning Outcome

After completing this practical, I understand intents, entities, utterances, language understanding model training, and the basic workflow of creating a question-answering solution.

## Conclusion

Language understanding helps AI applications identify user intentions, while question-answering systems provide relevant answers using available knowledge sources.
