
# Linux Shell Commands — Week 1

## Objective
To practise basic Linux/Debian shell commands as prescribed in the NAVTTC AI/ML course.

## Topics Covered
- Navigation: `pwd`, `cd`, `ls`
- File and directory operations: `mkdir`, `rm`, `rmdir`, `cp`, `mv`, `touch`
- Reading files: `cat`, `more`, `less`, `head`
- System commands and permissions: `sudo`, `man`, `chmod`, `ps`, `kill`, `dpkg`
- Shell operations: redirection, aliases, `nano`, `bash`, `sh`
- Package management, shutdown/restart, and environment variables
